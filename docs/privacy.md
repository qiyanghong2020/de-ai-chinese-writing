# Privacy and unpublished writing

The repository is a set of local instruction and reference files. It does not host a rewriting service, transmit documents, or collect manuscript text by itself.

Your text is still processed by the agent and model you choose. Before using any agent with confidential, unpublished, patient-related, legally privileged, or commercially sensitive material, review that provider's current data retention, training, access-control, and deletion settings.

## Hosted demo policy

A third-party “try it online” link should not be embedded merely because it is convenient. Before linking a hosted demo, the maintainer should be able to verify:

- who operates the service and who acts as data controller or processor;
- which model providers and subprocessors receive submitted text;
- whether prompts or outputs are stored, reviewed, or used for training;
- the retention period and a working deletion route;
- whether users can submit unpublished manuscripts or personal data;
- whether the demo clearly displays these terms before upload;
- who maintains the integration and handles incidents.

Until those points are documented, local installation is the safer default. Do not paste patient identifiers, credentials, confidential peer-review material, or an unpublished full manuscript into an unreviewed public demo.

## What the skill does not claim

- It does not determine whether a person or model wrote a passage.
- It does not guarantee a detector score.
- It does not replace journal, employer, or institutional disclosure policies.
