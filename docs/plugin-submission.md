### Short description

Make Chinese and English writing natural, specific, and evidence-faithful.

### Long description

Natural Writing Editor revises Chinese and English academic, medical, professional, and long-form prose while preserving facts, numbers, citations, uncertainty, genre, author intent, and legitimate World English. It diagnoses template-heavy phrasing locally and can audit long Viewpoints and framework papers for cross-section repetition, conceptual relabeling, decorative taxonomies, and low analytical increment. It does not chase detector scores, promise detector evasion, infer authorship from style, or invent evidence.

## Starter prompts

1. Rewrite this Chinese paragraph naturally without changing facts or citations.
2. Polish this English manuscript section while preserving evidence boundaries.
3. Audit this long Viewpoint for cross-section repetition and redundant taxonomies.

## Release notes

Initial public submission of De-AI Writing, a skills-only plugin containing the `de-ai-writing` workflow. Version 1.1.0 supports separate Chinese and English editing lanes, academic and medical safeguards, World English, local-scope protection, and document-level structural audits for long conceptual manuscripts. It adds Claude Code plugin packaging and a twelve-case synthetic evaluation specification while clearly separating deterministic contract tests from model end-to-end evaluation. It includes no MCP server, authentication, hosted rewriting endpoint, analytics service, or test credentials.
